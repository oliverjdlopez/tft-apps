# Preserved tft-suite catalogue

`catalog.json` is the byte-identical catalogue from the older `tft-suite`
checkout. Its immutable snapshots are retained in `../../snapshots/` alongside
the working suite's snapshots. This catalogue is an archival inventory, not the
active catalogue or a standalone snapshot root.

Preserving it does not seed or replace hosted datasets. The working suite keeps
its existing catalogue and imported unit expert cases. The authored 69-case
definitions are in
`../../../../eval-brainstormings/2026-09-30-code-grounded/`.
Source dataset IDs and earlier verification receipts refer to the old workspace.

See the suite's [retirement record](../../../../../docs/retiring-tft-suite.md)
for backup locations, verification and recovery.
