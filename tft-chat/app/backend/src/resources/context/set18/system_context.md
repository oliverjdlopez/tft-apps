# Set 18 System Context

Set 18, Enchanted Wilds, patch 18.1.

## Live system changes

- **Carousel** — returns in Set 18; may contain extra champions or higher-cost champions.
- **Crowd-control targeting** — recovering from CC no longer automatically forces a new target selection.
- **Missed PvE loot** — uncollected loot from 4-7 and subsequent PvE rounds can carry to the next PvE round.
- **Opening encounters** — new options are Completed Item Anvil Start, Reroll Subscription and Item Forge; removed options are Loot Subscription, Artifact Anvil and Reroll Start.

## Set and patch

Set 18 uses patch 18.1, including the August 31 balance changes and September 1 bug fixes.

Wisps have distinct shop timing, stage bands and eligibility requirements.
