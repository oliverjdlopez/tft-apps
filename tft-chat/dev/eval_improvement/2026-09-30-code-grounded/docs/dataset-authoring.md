# Lane dataset authoring contract

All writes stay within this run directory. Read the lane's reconciled `cases.md` and `reconciled-cases.json`, then verify relevant tool and evaluator source. Each lane is assigned independently to a GPT-6 Luna agent at high reasoning, per repository AGENTS.md. Do not edit application files, original research, Langfuse snapshots/catalog, configuration or data. Do not import, register, run live evaluations, query a production database, or browse for new outcome answers.

Produce `dataset.json` as an object with an `items` array compatible with `evals/langfuse/dataset_registration.py:register_dataset`. Each item uses `case` equal to the original stable ID; `input` is a string; `expected_output` contains case-specific `requirements` and an optional short `reference` explaining evidence-relative grading. Metadata contains `source_case_id`, `lane`, `subject`, original research path and lineage, `quality_profile: "answer_quality"`, `quality_threshold: 0.8`, and existing valid `deterministic_checks`. Omit suite-specific IDs so the file can be imported separately or combined. Do not invent a database name or scope ID. Use ACTIVE status; data readiness is an external preflight, not an assumption that observations were already collected.

Preserve the original question as the leading player question, except for the two explicitly adapted website-panel cases. Add a concise natural scenario paragraph where the research's fixed stars/items/roster constraints are absent from the question. The evaluated assistant sees input and runtime context, not `expected_output` or arbitrary metadata. Do not hide mandatory analytical constraints in grading-only fields. Keep code names and precise resolved identifiers out of player input; agents can formalize checks without forcing one brittle complete argument payload.

Use meaningful trace checks supported by `evals/trace.py` and `evals/utils.py`. `tool_called.value` is one string; `tool_called.values` is a list of alternative tools (OR). The check may include partial `arguments` and positive `min_count`. Object fields are recursive subsets, but lists are exact, including ordering and element shape; avoid brittle full cohort-condition lists. It does not guarantee success or a correct result. `tool_argument_resolved` supports only top-level argument fields, never nested cohort paths. Do not invent evaluator types such as `tool_output`, `jsonpath`, `sequence`, `metric`, `cohort_valid`, or nested resolved-name checks. Do not require display tools or redundant context retrieval. Hard checks should allow legitimate analytical routes; case-specific quality requirements must reject a superficial tool-call-only answer.

Cases about unobservable restrictions must preserve the investigation and explicitly define the supported approximation in input. Do not assert fully matched samples where the schema cannot enforce them. Do not turn every case into a refusal test. Multi-window and website cases use the coordinator's adaptation notes. Local reference files identify candidates but do not establish current balance or item uniqueness/legality.

Also write `authoring-report.md`: case count, important argument/check decisions, constraints added to input, remaining preparation gaps, and validation performed. Use the existing pure validators without writes by setting `PYTHONDONTWRITEBYTECODE=1`. Root will run import-path and semantic validation across all lanes. No agent may dispatch additional agents.

Grading caveat verified in source: the native quality judge receives `execution_evidence` containing a bounded trace summary and presentation extract, NOT full analytical tool outputs. Do not claim it independently certifies numerical grounding. Set metadata `grading_scope` to `investigation_behavior_and_answer_coverage` and `numeric_ground_truth_verified` to false. Keep factual fidelity requirements as the intended review contract, while reporting that exact numerical verification requires a frozen aggregate reference or full-trace audit. This does not require archiving cases or changing the runner.
