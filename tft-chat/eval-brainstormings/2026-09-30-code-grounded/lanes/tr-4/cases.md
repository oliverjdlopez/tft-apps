## TR-4-C01 — Six Juggernaut supporting packages

### Question

Is six Juggernaut really as flexible as people say, or do the Hunter/Primal and Summoner versions perform differently?

### Concrete analytical scenario

Exactly six recorded Juggernaut contributors in the primary slice; inspect Hunter/Primal, Summoner and overlapping support packages with declared itemized carry roles.

### Reference requirements translated to ChatTFT

Use the named Juggernaut contribution condition, discover actual carry pairs and support, then verify both joint package traits and unit conjunctions. compare_cohorts compares explicit package cells, keeping intersections separate and stratifying named carry/tank stars and loadouts.

### Metrics and acceptance checks

Report counts, recurrence and mean/top4/win for each package, not a single six-Juggernaut marginal. Preserve AP/AD item differences, named Gunblade holders and Maokai presence rather than assuming equal equipment from the trait count.

### Capability limits and preparation

Exactly six contributors is a deliberately narrower definition than all boards in a six-activation breakpoint band; report a broader band separately if used. Generic role, total-board budget and automatic family discovery remain unsupported.
